SANDLINE is a tactical round-based first-person shooter built with three.js: plant or defuse the bomb on Yard 7, a desert freight yard at dusk, against five patrolling bots. Buy rifles, an SMG, a sniper and grenades, manage your economy between rounds, and take the round before the clock runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
